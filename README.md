# PARADOX — interaktywne laboratorium nauki

Prototyp platformy edukacyjnej ze sprawdzanymi algorytmicznie ćwiczeniami z matematyki, biologii, angielskiego i informatyki.

## Uruchamianie

Wymagany Node.js 20+.

```bash
npm start
```

Aplikacja: http://127.0.0.1:4173

Testy:

```bash
npm run check
```

Opcjonalny tutor AI może korzystać z Ollama i modelu `qwen3.5:9b`. Bez Ollama ćwiczenia działają offline.

Szczegóły funkcji i ograniczeń znajdują się w [PARADOX_README.md](PARADOX_README.md).
