# Interaktywna aplikacja

Otwieranie z katalogu `docs/app/` przez `file://` nie jest zalecane, ponieważ przeglądarki ograniczają moduły JavaScript uruchamiane z dysku. Uruchom z głównego katalogu repozytorium `npm start` i wejdź na http://127.0.0.1:4173.

Kod tego katalogu jest też publikowalny przez GitHub Pages jako strona statyczna. Opcjonalny tutor AI wymaga serwera `server/server.mjs` i lokalnej Ollama; nie działa na samym GitHub Pages.
